TCP and UART gateways

Communication

Uses the selected gateway's TCP connection. Listening shows bytes received from UART, not other clients' outgoing requests. Replies on Raw gateways may include traffic from other clients.

Function is decimal (6 = 0x06, 66 = 0x42). FC01–04 use address/quantity; FC05/06 use address/value. Other functions use HEX data. Custom mode overrides address, quantity and value; CRC/MBAP is added automatically.

Sending shares the live serial bus. Pause other polling clients before a manual test to avoid overlapping requests.
